# 人文组 · 拼贴诗工作台

清华大学电子工程系团委人文组的社团主页（BBS 用），包含 **组织介绍** 与 **拼贴诗生成器** 两部分。

**一个文件就能跑**：`人文组.html` 双击打开即可，不需要联网、不需要安装任何东西。

---

## 怎么用

1. 下载 `人文组.html`（或直接用仓库里的那份）
2. 双击打开，浏览器里就能用
3. 想发给别人：把这**一个文件**发过去就行，图片、字体、脚本全在里面

手机上也能用，版式会自动变成单栏。

## 功能

**三个栏目**（顶栏切换，也支持直接链接）

| 栏目 | 链接 | 内容 |
| --- | --- | --- |
| 关于我们 | `#intro` | 时间线式组织介绍：四项活动，照片与文字左右交错 |
| 拼贴诗工作台 | `#studio` | 造词机 · 拼贴板 · 剪字 · 玩法说明 |
| 联系我们 | `#contact` | 联系方式 + 留言板（本地功能，见下） |

**造词机**：四个同构的列表，每个列表里勾选子分类、点「造词」出一批随机样例

- **短语**：10 种句法结构 × 555 个词的词库
- **句子**：论述整句 / 见闻陈述 / 抽象长句 / 诗性句 / 短句断句 / 名句成句（带出处）
- **词汇**：论述术语 / 抽象定语 / 抽象副词 / 抽象谓语 / 连接词 / 意象词
- **自定义**：自己写的词句，存在浏览器里，可选按空格标点拆成短词

**拼贴板**：造出来的词会变成一张张小纸片，拖到画布上、歪一点、叠一点、贴一截胶带；碎片可拖拽、旋转、缩放，双击改字。

**背景模板**：17 套纸（纯色 / 横线 / 方格 / 稿纸 / 信纸 / 牛皮纸 / 报纸 / 试卷 / 乐谱 / 日历 / 复写纸 …），一键随机；纸纹粗细可调。

**贴画质感**：每张纸片可单独调纸感（8 种）、褶皱强度、墨感（印刷墨水凹凸）、缺墨用量；有「随机质感」和「应用到全部」。

**剪字**：上传任何带文字的图片（杂志页、海报、截图），自动框出文字位置并把字抠出来（纸底透明）做成碎片。导入的图片只在你的浏览器里处理，不会上传。

**导出**：一键导出 1×/2×/3× 的 PNG，可加标题、去落款、透明背景、做旧调色。屏幕上看到的纸纹与墨迹会一起进导出图。

| `assets/logo/` | Logo 交付件（SVG），见下 |

> 需要改功能 / 重新打包，请拿完整开发版（见文末）。

## URL 参数（做 BBS 链接很方便）

| 参数 | 作用 |
| --- | --- |
| `#intro` / `#studio` / `#contact` | 直接打开某个栏目 |
| `?tpl=news` | 指定背景模板（plain / line / grid / manuscript / letter / kraft / news / exam / ivory / linen / aged / music / calendar / carbon / dark） |
| `?demo=1` | 预置一张示例拼贴，方便截图 |
| `?reset=1` | 忽略本地草稿，从空白开始 |

例：`人文组.html?tpl=manuscript&demo=1#studio`

## Logo

符号是「人」（人文组的人），方块构图。当前采用 **方案 B「拼贴」**：每笔拆成两段纸条、颜色深浅错开、压一截胶带。

| 文件 | 用途 |
| --- | --- |
| `mark-a.svg` | 方案 A · 几何构成 |
| `mark-b.svg` | 方案 B · 拼贴（**当前采用**） |
| `mark-c.svg` | 方案 C · 叠印 |
| `mark-b-plain.svg` | 方案 B 去底版（页面顶栏用的就是这个） |
| `favicon.svg` | 站点图标（笔画已加粗，保证 16px 下仍能辨认） |
| `lockup-h.svg` / `lockup-v.svg` | 横版 / 竖版组合标 |
| `compare.html` | 三个方案的对比页（含尺寸测试、深底色、顶栏实景） |
| `size-test.html` | 小尺寸可辨识度专项检查 |

组合标里的字是**系统字体**渲染的，交付给设计软件（Figma / Illustrator）时建议**转成曲线**，
否则换一台机器字体会变。徽标本身是纯路径，不存在这个问题。

## 数据与隐私

- 你导入的图片、造出来的词、拼好的作品，**全部只在你的浏览器里处理**，不会上传到任何服务器
- 拼贴草稿、自定义词句会自动存在本机浏览器，关掉再打开还在；换电脑 / 换浏览器不会同步
- **留言板目前是本地功能**：留言只存在你自己这台设备的浏览器里，刷新还在，但我们收不到、别人也看不到。
  想联系我们请发页面上的邮箱。留言板接后端的方案与注意事项，写在 `src/index.html` 的 HTML 注释里
  （需要开发版才能看到）
- 页面里的活动照片已做压缩并**去除 EXIF**（手机照片常带 GPS 定位信息）

## 兼容性

Chrome / Edge / Safari / Firefox 的近几年版本都可以。用到了 `backdrop-filter`、`aspect-ratio`、
`ResizeObserver`、CSS 变量与 `mix-blend-mode`，很老的浏览器（IE、旧版 Safari）不支持。

## 需要改功能？

这个仓库**只放发布文件**，源码、测试与构建脚本都在开发版里。需要其中任何一样，可以：

1. 从 git 历史里取回删除前的版本：
   ```bash
   git log --oneline --diff-filter=D -- src/script.js   # 找到删除它的那次提交
   git show <那次提交>^:src/script.js > script.js        # 取出文件
   ```
2. 或者找维护者要完整开发版（含 `src/` `test/` `tools/` 与全部验证脚本）

开发版里还有：造词引擎与语料库的单测、纸纹标定、导出视觉验证、
页面结构自检、留言板功能测试、Logo 交付件自检，以及本地预览服务器。
